# Aura Shot: year one review

A one-page, interactive review of Aura Shot's first year (Nov 2025 – Nov 2026):
ads, price, product page and repeat buyers, with the maths behind every number.

- Open `index.html` in any browser, or use the GitHub Pages link.
- No customer names, phone numbers or addresses are in this repository.
- The full formulas are in the "Aura Shot numbers tracker" spreadsheet.

Data checked on 17 Nov 2026. Sources: Meta Ads, order tracker, Shopify order emails.
